# Design and Development

Responsive landing section based on a Nicepage HTML template.

## Preview

Open `index.html` in a browser or deploy via GitHub Pages.

## Features

- Fully responsive (desktop / tablet / mobile)
- CSS Grid layout
- Soft orange watercolor-style background
- Card hover effects
- Clean typography (Open Sans)

## Deploy to GitHub Pages

1. Create a new repository on GitHub.
2. Push this folder content to the repository.
3. In repository Settings → Pages → Source: Deploy from a branch → `main` / root.
4. Your site will be available at `https://<username>.github.io/<repo-name>/`.
